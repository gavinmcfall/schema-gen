# schema-gen — Deprecated

This registry has been retired. Use [`k8s-schemas.home-operations.com`](https://k8s-schemas.home-operations.com) instead — same idea, better-maintained, GitOps-friendly, active community.

The hosts this project served (`kubernetes-schemas.nerdz.cloud` and `k8s-schemas.nerdz.cloud`) have been removed: Pages projects deleted, DNS records removed, no redirect or proxy in place. Any references must be updated to point at the home-operations origin.

If you forked or used this repo, see the upstream's [contributing guide](https://github.com/home-operations/k8s-schemas#contributing) for how to add CRD sources there.
